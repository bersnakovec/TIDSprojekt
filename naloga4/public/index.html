Deck svetovalec

Izberi turnirski deck ali prilepi svojega, povej, kako igraš in koliko želiš porabiti. Aplikacija iz tvojih izbir, besedil kart (Riftcodex) in cen (TCGplayer) sestavi prompt za LLM in prikaže njegov strukturiran odgovor v JSON.

Kako deluje

  1. Iz izbir v obrazcu in podatkov o decku strežnik sestavi prompt.
  2. Claude API vrne odgovor, omejen na JSON shemo (structured outputs).
  3. JSON se deserializira v razred DeckAdvice, ki preveri imena kart, domene, kopije, cene in proračun.
Podatki: Riftcodex (karte), TCGCSV / TCGplayer (cene), Frankfurter (USD → EUR), turnirski decki iz naloge 2.
